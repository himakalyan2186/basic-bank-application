# 🏦 Basic Bank Application

A simple **Bank Management System front-end** built using **HTML and CSS**.  
This project was created to practice web development concepts such as page design, navigation, forms, styling, and creating a multi-page banking interface.

## 📌 About the Project

The Basic Bank Application provides a simple interface that simulates common banking activities.

The project includes different pages for:

- 🔐 User Login
- 🏠 Welcome/Home Page
- 👤 Beneficiary Management
- 💸 Fund Transfer
- 📊 Fund Transfer Status
- 🚪 Logout

This is a **front-end practice project** and does not implement a real banking backend or actual financial transactions.

## ✨ Features

- Clean and simple banking interface
- Login page
- Welcome/dashboard page
- Beneficiary management
- Fund transfer interface
- Fund transfer status page
- Logout page
- Custom CSS styling
- Background images for different pages
- Navigation between multiple HTML pages
- Responsive-friendly page structure

## 🛠️ Technologies Used

- **HTML5** – Structure and content
- **CSS3** – Styling and page layout
